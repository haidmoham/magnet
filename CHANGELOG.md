# Changelog

## 0.1.0-alpha.3

- Add native Spotify playback with durable OAuth recovery, full saved-library loading, playlists, search pagination, and a manipulable session queue.
- Drive the visual layer and static-spectrum histogram from decoded PCM, with responsive smoothing, safe adaptive quality, and a wallpaper-backed static mode.
- Add first-launch instructions and a tag-driven GitHub Actions pipeline that rebuilds and publishes the Windows NSIS installer from the release commit.
